The first release of Ngwa, a fast, native Matrix client. No browser engine,
no Electron: one small app for Windows, macOS and Linux.

**This is an early release for unencrypted rooms.** Encrypted rooms and DMs
show in your list, but their messages read "Encrypted message" until
end-to-end encryption arrives in v0.2. Most private rooms and DMs are
encrypted by default, so for now Ngwa is best for public rooms.

## What works

- Sign in with your Matrix ID and password, on matrix.org or any homeserver
  that supports sliding sync. Your session is kept in your system's
  credential store.
- Your room list appears almost immediately and stays live, with unread
  counts, mentions, the latest message, and search (Ctrl+K).
- Open a room to read it, scroll back through its history, send messages and
  reply to them. Links are clickable.
- Accept or decline invites.
- A failed message says why, and can be retried or deleted.

## Download

| System | File |
| --- | --- |
| Windows 10 and 11 | `ngwa-windows-x86_64.zip`: unzip and run `ngwa.exe` |
| macOS 11 or later, Apple silicon and Intel | `ngwa-macos-universal.zip`: unzip and move Ngwa to Applications |
| Linux x86_64 | `ngwa-linux-x86_64.tar.gz`: unpack and run `./install-linux.sh` |

The builds aren't signed by Apple or Microsoft yet, so the first launch
needs one extra step:

- **macOS:** right-click Ngwa, choose **Open**, then **Open** again.
- **Windows:** if SmartScreen appears, choose **More info**, then
  **Run anyway**.

Check a download against `SHA256SUMS.txt` if you like.
